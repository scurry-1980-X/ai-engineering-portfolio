## Version History

### v0.1 — Command-Line Prototype
- Built the first command-line version of the AI IT Support Assistant.
- Allowed a user to enter an IT issue and receive AI-generated troubleshooting guidance.

### v0.2 — OpenAI API Integration
- Connected the app to the OpenAI API.
- Added AI-generated support analysis using a structured troubleshooting prompt.

### v0.3 — IT Support Categories
- Added approved IT support categories.
- Added support for category, subcategory, priority, likely cause, troubleshooting steps, and escalation guidance.

### v0.4 — GUI Version
- Added a Tkinter desktop interface.
- Added text input for IT issue descriptions.
- Added an output area for AI-generated troubleshooting analysis.
- Added Clear and Save Analysis buttons.

### v0.5 — Workflow and Responsible AI Improvements
- Added a responsible-AI disclaimer.
- Improved code organization.
- Added timestamp support for saved analysis files.
- Improved GUI responsiveness during analysis.

### v0.6 — Ticket Output Mode
- Added selectable output modes for Troubleshooting Analysis and Ticket Notes.
- Added ticket-style fields including Ticket Summary, Impact, Urgency, Priority, Recommended Assignment Group, Technician Notes, and Escalation Guidance.
- Updated saved analysis files to include the selected output mode.
